# radar-local

Prototipo experimental de herramienta de inteligencia territorial para detectar oportunidades económicas de proximidad en municipios y comarcas.

El aplicativo permite seleccionar una actividad económica, visualizar oferta existente orientativa, posibles zonas de oportunidad y añadir señales locales aportadas por vecinos, emprendedores o agentes de desarrollo local.

## Objetivo

Explorar cómo combinar datos territoriales, análisis geográfico y conocimiento local para apoyar decisiones iniciales de emprendimiento en entornos rurales y municipios intermedios.

## Estado del proyecto

Versión 0.3 — Prototipo local.

Los datos incluidos son simulados/orientativos y se utilizan únicamente para demostrar la lógica de funcionamiento. No constituyen un estudio de viabilidad ni una recomendación de inversión.

## Funcionalidades actuales

- Mapa interactivo centrado en La Palma del Condado.
- Selector de actividades económicas.
- Ficha de oportunidad orientativa.
- Capa de oferta existente simulada.
- Zonas sugeridas de oportunidad.
- Registro de señales locales.
- Circuito básico de validación: vecinal, ADL/técnico, validada o descartada.
